# Superset Dashboard — Contract-Driven Platform

> **Python version note:** Superset requires Python <=3.12. This project runs Python 3.13
> locally, so Superset must be run in a dedicated venv:
> ```bash
> pyenv install 3.12.0   # or brew install python@3.12
> python3.12 -m venv .venv-superset
> source .venv-superset/bin/activate
> pip install apache-superset==4.0.2
> ```

## Setup

### 1. Install and initialise Superset (Python 3.12 venv)
```bash
export SUPERSET_SECRET_KEY="contract-driven-platform-superset-key"
superset db upgrade
superset fab create-admin \
  --username admin --firstname Archit --lastname Raj \
  --email araj2210@gmail.com --password admin
superset init
```

### 2. Seed Gold data (dev mode — skip when S3/Delta is live)
```bash
python observability/dashboards/seed_gold_data.py
```

### 3. Start Superset
```bash
export SUPERSET_CONFIG_PATH=/Users/architraj/contract-driven-platform/observability/dashboards/superset_config.py
superset run -p 8088 --with-threads --reload
```

### 4. Create datasources and dashboard via API
```bash
python observability/dashboards/setup_superset_datasources.py
```

### 5. Open dashboard
http://localhost:8088  (login: admin / admin)

## Dashboard: Contract-Driven Platform — Pipeline Health

### Charts

| Chart | Source Table | Type | Purpose |
|-------|-------------|------|---------|
| Daily Gross Revenue by Currency | gold_daily_order_revenue | Line | Revenue trend over time |
| Daily Order Count | gold_daily_order_revenue | Bar | Order volume per day |
| Payment Success Rate by Method | gold_payment_success_rate | Line | Success % per payment method |
| Contract Violations by Topic | gold_pipeline_health | Area | DLQ violations stacked by topic |
| DLQ Error Type Breakdown | gold_pipeline_health | Pie | Distribution of error types |

### Production connection (after S3/Delta is live)
Replace the SQLite connection with a Spark SQL connection:
- SQLAlchemy URI: `hive://localhost:10001/default`

Or use the Trino adapter pointed at your Delta tables on S3.
